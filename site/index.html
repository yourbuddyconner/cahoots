Keys agreed in a room.

Cahoots is in-person key agreement for the protocols you already run. A group meets once. Their badges touch and build a shared pad of random bytes. That pad is a key budget for WireGuard tunnels, encrypted files, group chat, and approvals.

Run a ceremony in your browser Read the protocol →

Your browser can't draw the badge in 3D. The parts are listed below.

  1. Polycarbonate shellsCard-sized, with four screws and a lanyard slot. The shells are transparent because the chip's silicon is open to inspection, and the case should be too.
  2. 1.54" e-paperShows the six check words and keeps them on screen with no power. Members read them aloud. If every screen matches, every pad matches.
  3. Baochip-1xA hardware random number generator with health tests, a key store, and one-way counters. The pad lives in on-die RRAM and is erased byte by byte as it is spent.
  4. Touch linkFour spring pins on one edge. Gold pads and magnets on the other. Badges snap into a ring and swap contributions over the wire. No radio.
  5. Battery and USB-CA 400 mAh cell runs the badge for a day at the table. USB-C charges it. Before a ceremony, USB-C can also load YubiKey bytes from a laptop. It is never connected during one.

What it does

The pad is a key budget.

Spend 32 bytes

Seed a session of any size in a protocol you already run. Each of these protocols has a slot for a secret that both sides already share. The slot is almost always empty, because sharing the secret was the hard part. The ceremony fills it.

An attacker must break the math and know the pad

Spend one byte per byte

Encrypt a short message as a true one-time pad with a one-time Poly1305 tag. Use it for approvals, key announcements, and the words you say at the start of a call. A 256 KiB pad holds about two thousand such messages.

Information-theoretic, as long as no byte is reused

Rotate by pointer

A rotation is a public note that says which bytes come next. Both sides spend the same offset, derive the same key, and erase the bytes. There is no coordination server and no certificate authority.

Every spend is ledgered and erased before the key leaves

The ceremony

Five steps, in a room.

  1. Agree. One member sets the circle name, size, and pad length. Every screen shows them. Everyone confirms.
  2. Commit. Each badge draws random bytes from its hardware generator and shares a hash of them. After that, nobody can change their contribution.
  3. Reveal. Badges touch in a ring and pass contributions around until every badge holds all of them. Each badge checks every contribution against its hash.
  4. Combine. Every badge XORs every contribution into one pad. If at least one member was honest, the pad is random.
  5. Say the words. Six words from the pad appear on every screen. Members read them aloud. A mismatch means start over.

Hardware

Concentric rings of security.

Anyone can build a badge from what is on the bench. A circle is only as protected as its least protected member. The ceremony shows the circle's tier before anyone confirms.

T0PhoneThe protocol runs. Erasure is best effort.
T1Any microcontrollerReal erasure in a raw partition. A stolen device is a copy of the pad.
T2SealedSecure boot and flash encryption. A dumped flash is ciphertext.
T3Key storeThe key that wraps the pad never leaves the chip. Each wrong PIN burns a one-way counter. At the limit, the badge erases the pad.
T4InspectedA member has compared the silicon with the published design under a microscope. This is the badge we make.

Numbers Station

A public feed only the circle can read.

During the Cold War, shortwave stations read out strings of numbers. Anyone could hear them. Only the agent who held the matching pad page could read them.

Cahoots keeps the idea. Ciphertext goes on an append-only feed. Anyone can read it. Only circle members can decrypt or forge an entry. That holds against the operator too. The feed orders messages and refuses any reuse of pad bytes it can see. Its head is anchored, so nobody can rewrite history.

Build

  
Four traits make a badge.

  

    
Entropy
A hardware random source with SP 800-90B health tests. If a test fails, the ceremony stops.

    
PadStore
Raw non-volatile memory with an erase unit. Spent bytes are overwritten and read back.

    
Display and Link
A screen that can show six words, and a wire to the next badge. The desktop simulator is the reference implementation and the test harness.
